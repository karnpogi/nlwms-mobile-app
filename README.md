# NEU Monitoring App

_A mobile and web-based academic task management system exclusively for NEU faculty and staff._

![Flutter](https://img.shields.io/badge/built%20with-Flutter-blue.svg) ![Laravel](https://img.shields.io/badge/backend-Laravel-red.svg) ![License](https://img.shields.io/badge/status-in%20development-yellow)

---

## 🚀 Overview

Docelio is a mobile-first academic task management tool designed to streamline faculty workflows such as task assignments, reporting, and collaboration. Built with Flutter (mobile) and Laravel (web admin backend), the system empowers faculty with a reliable and user-friendly interface while allowing administrators to manage users and monitor academic activities.

---

## 🎯 Features

### ✅ Mobile (Flutter)
- Faculty login & signup
- Task dashboard with summaries
- Recent tasks view
- Quick actions (create, view, report)
- Settings & user profile

### 🛠 Web (Laravel)
- Admin dashboard
- User & role management
- Task reports overview
- Database management

---

## 🧩 Tech Stack

| Layer      | Technology             |
|------------|------------------------|
| Mobile App | Flutter                |
| Backend    | Laravel 10+ (REST API) |
| Database   | MySQL                  |
| State Mgmt | `Provider` (Flutter)   |
| Auth       | Sanctum (Laravel API)  |
